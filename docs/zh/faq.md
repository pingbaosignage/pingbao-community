# 屏宝 (Pingbao) 常见问题解答 (FAQ)

### Q1. 现场网络中断或断网时，屏幕会出现黑屏或卡死吗？
**A:** 完全不会。屏宝系统核心基于**“断网离线自主循环 (Autonomous Offline Loop)”**标准设计。标牌终端在播放前已将所有音视频素材及排期规则完全下载至机身本地闪存中。即使断网数小时甚至数天，终端也会严格按照内置时间表永久自主循环播放。

### Q2. 屏宝支持哪些类型的商业标牌硬件？
**A:** 原生深度支持三星商用智能标牌 Standalone 硬件（搭载 Tizen 6.5+ / SSSP 10+ 系统的 QMB, QBB, QHB, QMC, QBC, QHC 等全系列）。此外，还提供标准的 Web Player 网页播放器内核，可在标准 PC 浏览器及各类安卓商用工控机上稳定运行。

### Q3. 上传视频有大小限制吗？支持哪些编码格式？
**A:** 强烈建议使用 H.264 / AAC 编码封装的 MP4 及 WebM 格式文件。服务端支持流式切片上传与断点分块分发，支持单文件数 GB 级别超高清视频素材的流畅传输与下发。

### Q4. 节目排期的四级优先级与分时时段 (Dayparting) 是如何运作的？
**A:** 屏宝支持 `EMERGENCY` (P:100~200, 紧急插播) > `EVENT` (P:50~99, 营销活动) > `REGULAR` (P:10~49, 日常分时) > `DEFAULT` (P:0, 兜底背景) 四级抢占机制。高优先级的活动时段到期后，屏幕会自动平滑回落至常态时段，无需人工干预，全程零黑屏零闪烁。

### Q5. 什么是 SyncPlay 多屏同步播放？需要特殊网络硬件吗？
**A:** SyncPlay 是专为前台联排电子餐牌打造的帧级同步技术。基于标准局域网 NTP 时钟对齐与组播广播，各屏幕在切换菜品或播放超宽大片时毫秒级协同翻页，不需要任何额外的矩阵或视频拼接器硬件。

### Q6. 错误遥测系统会上传哪些数据？如何保障企业数据隐私？
**A:** 错误遥测默认严格关闭（Opt-in），必须由超级管理员手动授权。在捕获服务异常时，系统会自动进行深度脱敏，清洗密码、Token、Bearer 头、局域网/公网 IP 及手机号等隐私，仅提取去除敏感信息的堆栈指纹回传至开源社区，加速版本修复。

### Q7. 发现软件缺陷 (Bug) 或有新功能建议，应如何反馈？
**A:** 请前往 [屏宝社区 Issue 反馈中心](https://github.com/pingbaosignage/pingbao-community/issues)，选择**缺陷反馈 (Bug Report)** 或 **功能建议 (Feature Request)** 模板提交。管理团队评审并标记 `accepted`（已受理）标签后，AI 智能体将自动进入代码开发与测试构建流程。
