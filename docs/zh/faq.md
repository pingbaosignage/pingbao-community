# 屏宝 (Pingbao) 常见问题解答 (FAQ)

### Q1. 全新内置的“屏宝 AI 运维助手”能做什么？会不会误操作导致全国门店同时受影响？
**A:** 在任意页面点击右上角 **【AI 助手】按钮（快捷键 `Ctrl+J`）**即可滑出智能对话窗。您可以用自然语言：① 以表格汇总服务器健康度与各系统在线屏幕，② 一键排查离线设备与在播过期促销海报，③ 通俗解读底层报错日志，④ 下达音量、亮度、息屏、重启、定时策略或智能排程草稿指令。  
系统内置双重安全防线：所有控制指令均采用**人工确认审批制 (HITL)**，必须由管理员在预览卡片点击 **【确认并执行】** 才会生效；同时具备**严格设备子集隔离 (Strict Subsetting)**，仅锁定当前已选屏幕，彻底杜绝全网误发事故。

### Q2. 企业担心云端大模型费用或内网数据安全，能否免费连接本地私有化大模型？
**A:** 完全支持！在 **【系统设置 > AI / 大模型自动化】** 中选择 **【私有化本地部署 / OpenAI 兼容 (Ollama · vLLM)】**，即可零 API 费用直连企业内网部署的开源大模型（如 `gemma4`、`qwen2.5`、`deepseek-r1`、`qwen2.5vl`），所有运维数据 100% 留存内网。若使用云服务，系统也原生内置通义千问、DeepSeek、智谱 GLM、字节豆包、Kimi 以及 OpenAI、Gemini、Claude 一键预设。

### Q3. AI 如何防止过期的营销活动海报继续在门店大屏播出？
**A:** 上传图片或视频素材时，**多模态视觉 AI** 会自动识别电子菜单/促销类型、商品名称、推荐播放时段以及画面中的**活动截止日期 (`detected_valid_until`)**。一旦活动到期但仍留在在播排程中，`【AI 晨间简报】`、`【AI 排程校验】` 与 AI 助手会立即发出醒目预警，提前拦截播出事故。

### Q4. 门店网络中断会导致黑屏吗？支持哪些硬件终端？
**A:** 绝不会黑屏。屏宝采用**断网永久自治循环架构**，所有素材与四级分时排程均预先缓存至本地存储。系统深度适配**三星智能商用标牌 (Tizen 6.5+ / SSSP 6~10+)** 原生硬件控制，同时统一支持 **Windows (`.exe`)、Android (`.apk`)、Linux (`.deb`/`.sh`) 与 Web (`/player`)** 五大平台，下载的安装包均自动写入服务器地址，输入 6 位 PIN 码即可完成配对。

### Q5. 多屏同帧同步 (SyncPlay)、外部 MCP 接口与日志留存周期是如何工作的？
**A:** 当多台屏幕处于**【同一分组 + 同一排程 + 同一局域网】**时，系统通过实时 SSE 流与时钟偏移校准实现 **100% 零配置毫秒级同帧同步切换**。除内置 AI 助手外，系统还内置标准 `pingbao` **MCP 服务**供 Claude、Cursor、Antigravity 等外部智能体接入；所有运维、开机时长、PoP 与审计日志默认执行 **6 个月（180 天）自动留存与滚动清理策略**。
