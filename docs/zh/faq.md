# 屏宝 (Pingbao) 常见问题解答 (FAQ)

### Q1. 门店网络中断或断网时，屏幕会出现黑屏或卡死吗？
**A:** 完全不会。屏宝核心基于**“断网永续自主循环 (Autonomous Offline Loop)”**架构设计。所有音视频素材与排期规则在开播前已预缓存至终端本地存储，即使外网长时间中断，终端依然依托本地状态机与时钟 24/7/365 精准无缝轮播，零黑屏、零报错。

### Q2. 屏宝支持哪些操作系统与商用标牌硬件？
**A:** 屏宝以**三星智能商用标牌 (Samsung Smart Signage · Tizen 6.5+ / SSSP 6~10+)** 底层原生 `b2bapis` 硬件深控为核心，同时全面支持 **Windows 10/11 工控机与自助终端 (`.exe`)**、**Android 广告机/机顶盒/平板 (`.apk`)**、**Linux 迷你主机 (`.deb` / `.sh`)** 以及**免安装标准网页播放器 (`/player`)** 五大平台统一管控。系统内置多系统硬件抽象层 (HAL)，可在混合 OS 批量控制时自动适配背光调节、DPMS 息屏休眠与系统重启能力。

### Q3. 现场安装播放器时需要逐台手动输入服务器 IP 地址吗？
**A:** 无需手动输入。从控制台顶部 **[下载播放器安装包]** 弹窗下载的所有安装包（三星 Tizen USB 自动安装压缩包、Windows `.exe`、Android `.apk`、Linux `.deb`/`.sh`）均已自动内嵌（Stamping）当前服务器访问地址，现场装好即连，直接显示 6 位配对 PIN 码极速纳管。

### Q4. 上传视频有大小限制吗？推荐哪些编码格式？
**A:** 推荐使用 H.264 / AAC 编码封装的 MP4 及 WebM 格式。服务端采用 64 字节二进制魔数安全校验与磁盘直连流式分块上传技术，支持数 GB 级 4K 超高清视频素材的稳定传输与分发。

### Q5. 节目排期的四级优先级与分时时段 (Dayparting) 是如何运作的？
**A:** 屏宝支持 `EMERGENCY` (P:100~200, 紧急插播) > `EVENT` (P:50~99, 高峰活动) > `REGULAR` (P:10~49, 日常分时) > `DEFAULT` (P:0, 兜底轮播) 四级抢占机制。高峰时段结束后屏幕自动平滑回落至常态节目，全程零黑屏零闪烁。

### Q6. 什么是 SyncPlay 多屏同步播放？如何启用？
**A:** 无需额外拼接器或复杂手动设置。只要多台商用屏满足**【同一设备分组】+【相同节目排期】+【同一局域网】**三个条件，系统即通过实时 SSE 同步流与时钟偏移自动校准技术**全自动激活**毫秒级帧同步翻页与联屏播放。

### Q7. 屏宝支持外部系统集成与 AI 智能体 (MCP) 吗？
**A:** 全面支持。平台提供 60+ 标准化 OpenAPI 3.0 RESTful 接口并原生内置 **MCP (Model Context Protocol)** 服务端，支持细粒度权限范围 API 密钥签发与调用量监控，允许 Claude Desktop、Cursor、Antigravity 等大模型智能体通过自然语言巡检设备、查询开机时长并自动编排下发排期。

### Q8. 运维与审计日志保留多久？错误遥测如何保障企业隐私？
**A:** 运维指令记录、设备开机时长统计、播放凭据 (PoP) 与全员操作审计日志默认执行 **6 个月（180 天）留存周期与自动清理机制 (Auto-Purge Lifecycle)**，兼顾合规审计与磁盘长效健康。错误遥测默认严格关闭（Opt-in），仅在超级管理员显式授权后开启，并在上传前强制脱敏所有密码、密钥、Token 与 IP（替换为 `***MASKED***`），通过 SHA-256 指纹去重后提交至官方社区。
