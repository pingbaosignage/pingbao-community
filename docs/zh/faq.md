# 屏宝 (Pingbao) 常见问题解答 (FAQ)

### Q1. 全新上线的“对话式外部联动代理”与“AI 内容修改工作室”有什么区别和配合关系？
**A:** 两者实现了**“外部实时数据采集”**与**“商显画面定制呈现”**的彻底解耦：
* **对话式外部联动代理（`外部联动代理`菜单）**：无需写代码，直接对话如*“帮我接入沪深A股四大核心指数”*或*“接入上海实时天气”*，系统即可完成接口连接、AES-256 密钥加密存储与定时任务累积写入**数据采集池**；接入成功的接口还会保存为**已学习 API 记忆卡片**供下次一键复用。
* **AI 内容修改工作室（`+ 基于此数据新建内容` / `✨ AI 修改`）**：围绕同一个实时数据池，您可以用自然语言（如*“切换黑金主题并开启 7 日走势图”*）衍生出多套完全独立的 16:9 HTML5 看板（如大堂迎宾全屏、贵宾室走势屏、电梯间极简屏），分别自由排期上屏。

### Q2. 企业内网私有 ERP/库存接口也能安全接入吗？如果外部接口异常会搞乱门店屏幕吗？
**A:** 完全安全可控。系统默认启用 **防 SSRF 隔离**，仅允许超级管理员在 **【内网安全白名单 (ALLOWLIST)】** 中显式授权的内网域名或网段通信；一旦外部接口异常返回大批量删除或修改，**批量变更熔断器**会立即中止入库并转入 **【隔离审批箱 (QUARANTINE)】**，待管理员核对差异确认后方才生效。

### Q3. 什么是「AI 智能配方」？使用 AI 助手远程控制时有没有误发全网门店的风险？
**A:** 右上角 **【AI 助手】 (`Ctrl+J`)** 顶部的 **AI 智能配方**内置了`周末门店模式`、`夜间打烊休眠`等一键运行芯片，并可通过 **`【+ 记忆近期任务】`** 自动学习您的连环运维习惯。  
所有管控指令与智能配方均受 **人工确认制 (HITL)** 保护，必须点击 **【确认并执行】** 才会下发，且 **严格子集隔离 (Strict Subsetting)** 会将目标牢牢锁定在当前已选设备，彻底杜绝全网误发。

### Q4. 担心云端大模型费用或企业数据出境，可以接入免费内网本地大模型吗？
**A:** 100% 支持！在 **【系统设置 > AI / 大模型自动化】** 中选择 **`本地私有化部署 (Ollama · vLLM)`**，即可零 API 费用、零外网连接直连内网开源模型（如 `gemma4`、`qwen2.5`、`deepseek-r1`、`qwen2.5vl`）；同时亦内置通义千问、DeepSeek、智谱 GLM、豆包、Kimi、OpenAI、Gemini、Claude 与 FreeLLMAPI 共 **11 大预设**。

### Q5. 上传 HTML5 触控压缩包 (`.zip`) 或运行动态数据看板时，支持远程实时截屏验屏吗？
**A:** 支持！全新升级的 **多系统播放器 `v2.2.0`** 不仅支持三星 SSSP 硬件帧缓冲截屏，还能实时高清回传动态 HTML5 数据组件与触控终端界面的真实渲染画面，足不出户即可核验播出效果。

### Q6. 如何防止过期促销海报继续轮播？门店断网会黑屏吗？
**A:** 素材上传时 **多模态视觉 AI** 会自动识别画面中的**活动截止日期 (`detected_valid_until`)**，一旦排期中存在过期海报会立即在晨间简报与排程校验中预警；同时所有视频、图片与 HTML5 包均预先下载至终端本地高速缓存，即使长期断网也能 **7×24 小时自治轮播**。

### Q7. 四级排期优先级、零配置 SyncPlay 与外部智能体 MCP 如何协同？
**A:** 排期按 `紧急 > 活动 > 常规 > 垫片` 自动抢占并无感恢复；满足**【同一分组 + 同一排程 + 同一局域网】**的多块屏幕通过 SSE `sync-stream` 实现毫秒级同帧切换；此外系统内置标准 **`pingbao` MCP 服务**与 60+ REST API，可直接接入 Claude Desktop、Cursor、Antigravity 与 Dify 等外部智能体。
