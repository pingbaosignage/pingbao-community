# 핑바오(Pingbao) 자주 묻는 질문 (FAQ)

### Q1. 새로 추가된 ‘핑바오 AI 오퍼레이터 챗봇’으로는 어떤 작업을 할 수 있나요? 실수로 전체 매장이 제어될 위험은 없나요?
**A:** 화면 우측 상단의 **`[AI 챗봇]` 버튼(단축키 `Ctrl+J`)**을 누르면 언제든 대화창이 슬라이드됩니다. 자연어로 ① 서버 CPU/디스크 헬스 및 OS별 온라인 단말 표(Table) 조회, ② 오프라인 기기 및 기한 만료 프로모션 배너 색출, ③ 단말 에러 로그 원인 해설, ④ 볼륨·밝기·화면 전원·재부팅·전원 타이머·스마트 스케줄 초안 생성을 지시할 수 있습니다.  
특히 **사고 제로 안전 설계**가 적용되어 있어, 제어 명령은 절대 즉시 실행되지 않고 반드시 **실행 미리보기 카드(`승인 대기`)**를 먼저 띄우며 운영자가 **`[승인 및 실행]`**을 클릭할 때만 작동합니다. 또한 **엄격한 대상 격리(Strict Subsetting)** 가드가 선택된 기기 외 전체 매장으로의 오발송을 원천 차단합니다.

### Q2. 외부 클라우드 AI 요금이나 사내 데이터 외부 유출이 걱정됩니다. 무료 폐쇄망 AI 연동이 가능한가요?
**A:** 100% 가능합니다! **`[시스템 설정 > AI / LLM 자동화]`**에서 **`온프레미스 / 사내 구축형 (Ollama · vLLM)`** 프리셋을 선택하면 외부 인터넷 연결이나 API 요금 부담 없이 사내 서버의 오픈소스 모델(`gemma4`, `qwen2.5`, `deepseek-r1`, `qwen2.5vl` 등)과 직접 연결되어 모든 매장 데이터를 100% 사내 폐쇄망 안에서만 안전하게 처리합니다. 물론 OpenAI, Google Gemini, Anthropic Claude 및 중국 본토 직결 모델(통의천문 Qwen, DeepSeek, GLM, Doubao, Kimi)도 원클릭 선택만으로 지원합니다.

### Q3. 기간이 지난 프로모션 배너가 매장에 계속 노출되는 방송 사고도 AI가 막아주나요?
**A:** 네, **멀티모달 비전(Vision) AI 자동 검수** 기능이 이미지나 영상을 업로드하는 즉시 메뉴 품목, 가격표(OCR), 권장 편성 시간대와 함께 배너 속 **행사 종료일(`detected_valid_until`)**을 자동 추출합니다. 종료일이 지난 배너가 활성 스케줄에 포함되어 있으면 대시보드 `[AI 모닝 브리핑]`, 스케줄 `[AI 편성·타이머 점검]`, 그리고 AI 챗봇이 즉시 경고하여 오송출 사고를 사전에 차단합니다.

### Q4. 매장 인터넷이 끊어지면 화면이 멈추거나 검은 화면이 되나요?
**A:** 전혀 그렇지 않습니다. 핑바오는 **"영구 자율 오프라인 재생(Autonomous Offline Loop)"**을 지원합니다. 스케줄 배포 시 모든 비디오 및 이미지 파일이 단말 로컬 스토리지에 사전 다운로드되며, 단말 내부 상태 머신으로 동작하므로 장기간 통신이 단절되어도 스케줄에 맞춰 무중단 재생됩니다.

### Q5. 어떤 운영체제(OS)와 상용 사이니지 하드웨어를 지원하나요?
**A:** **삼성 스마트 사이니지(Samsung Smart Signage · Tizen 6.5+ / SSSP 6~10+)** 심층 하드웨어 제어를 주력으로 하며, **Windows 10/11 키오스크(`.exe`)**, **Android 셋톱박스/태블릿(`.apk`)**, **Linux 미니 PC(`.deb` / `.sh`)**, **무설치 표준 웹 플레이어(`/player`)** 까지 **5대 멀티 OS 통합 관제**를 공식 지원합니다.

### Q6. 현장 기기에 플레이어를 설치할 때 매번 서버 IP나 주소를 수동 입력해야 하나요?
**A:** 수동 입력이 필요 없습니다. 콘솔 상단의 **[플레이어 설치 다운로드]** 모달에서 제공하는 전 OS 설치 패키지에는 현재 서버 접속 주소가 자동 내장(Stamping)되어 있어 설치 후 화면에 뜨는 6자리 PIN 코드만 입력하면 즉시 페어링됩니다.

### Q7. 4계층 스케줄 우선순위와 전 자동 SyncPlay 멀티스크린 동기화는 어떻게 작동하나요?
**A:** 스케줄은 `EMERGENCY`(긴급) > `EVENT`(피크 이벤트) > `REGULAR`(일반 타임파팅) > `DEFAULT`(24시간 기본 루프) 순으로 선점 후 자동 복귀합니다. 또한 여러 대의 디스플레이가 **【같은 그룹】 + 【같은 스케줄】 + 【같은 네트워크(LAN)】** 조건을 충족하면 별도 분배기 없이 실시간 SSE 스트림과 클럭 보정을 통해 밀리초 단위로 동시 화면 전환됩니다.

### Q8. 외부 AI 에이전트(MCP) 연동과 로그 보존 정책은 어떻게 되나요?
**A:** 빌트인 AI 챗봇 외에도 60+ OpenAPI 3.0 REST API와 표준 **MCP 서버(`pingbao`)**를 내장하여 Claude Desktop, Cursor, Antigravity 등 외부 에이전트 연동을 지원합니다. 모든 운영·가동·PoP·감사 로그는 **기본 6개월(180일) 보존 및 자동 정리(Auto-Purge)** 주기가 적용되며, Opt-in 오류 텔레메트리는 민감 정보를 `***MASKED***` 처리한 뒤 전송합니다.
