# 핑바오(Pingbao) 자주 묻는 질문 (FAQ)

### Q1. 새로 추가된 ‘대화형 외부연동 에이전트’와 ‘AI 컨텐츠 수정 스튜디오’는 어떻게 다른가요?
**A:** 두 기능은 **“외부 데이터 자동 수집”**과 **“사이니지 화면 맞춤형 디자인”**을 완벽히 분리해 주는 핵심 파이프라인입니다:
* **대화형 외부연동 에이전트 (`외부연동 에이전트` 메뉴)**: 코딩 없이 *"코스피 실시간 상위 종목 연결해줘"*, *"서울 매장 날씨 알려줘"*라고 채팅하면 API 연결, AES-256 인증키 보관, 주기적 크론(Cron) 수집 및 **데이터 피드 스토어 축적**을 자동 구성합니다. 한 번 연결한 API는 **학습된 API 스킬 카드**로 기억되어 다음번엔 원클릭으로 재사용할 수 있습니다.
* **AI 컨텐츠 수정 스튜디오 (`+ 이 데이터로 새 컨텐츠 만들기` / `✨ AI로 수정`)**: 수집·축적된 동일한 데이터 피드를 바탕으로 *"럭셔리 골드 테마에 7일 추세 그래프 켜줘"*처럼 자연어로 지시하여 **여러 개의 서로 다른 16:9 HTML5 사이니지 컨텐츠**를 독립 제작하고 각 매장 스케줄에 자유롭게 편성할 수 있습니다.

### Q2. 사내 폐쇄망 ERP/재고 API도 안전하게 연결할 수 있나요? 외부 API 오류로 매장이 망가질 위험은 없나요?
**A:** 안전하게 설계되어 있습니다. 기본적으로 내부망 IP 호출을 막는 **Anti-SSRF 방어**가 작동하며, 최고 관리자가 **`[사내망 호스트 허용 목록 (ALLOWLIST)]`**에 명시 승인한 사내 도메인/CIDR만 통신할 수 있습니다. 또한 외부 API 장애로 대량 변경이나 비활성화가 발생하면 **서킷브레이커 격리 승인함(`QUARANTINE`)**이 자동 반영을 즉시 멈추고 관리자가 변경 내역(Diff)을 승인할 때만 반영합니다.

### Q3. ‘핑바오 AI 오퍼레이터 챗봇’과 ‘AI 스마트 레시피’는 무엇이며, 전체 매장 오발송 위험은 없나요?
**A:** 우측 상단 **`[AI 챗봇]` (`Ctrl+J`)** 상단에 위치한 **AI 스마트 레시피**는 `주말 매장 모드`, `야간 마감 절전` 등 자주 쓰는 복합 작업을 원클릭 칩으로 실행하거나 **`[+ 최근 작업 기억]`**으로 나만의 운영 루틴을 학습시키는 기능입니다.  
모든 제어 명령과 스마트 레시피는 절대 즉시 실행되지 않고 **실행 미리보기 카드(`승인 대기`)**를 먼저 띄우며, **엄격한 대상 격리(Strict Subsetting)** 가드가 선택된 기기 외 전체 매장으로의 오발송을 원천 차단합니다.

### Q4. 외부 클라우드 AI 요금이나 사내 데이터 외부 유출 없이 무료 폐쇄망 AI 연동이 가능한가요?
**A:** 100% 가능합니다! **`[시스템 설정 > AI / LLM 자동화]`**에서 **`온프레미스 / 사내 구축형 (Ollama · vLLM)`** 프리셋을 선택하면 API 요금 0원, 외부 데이터 유출 0건으로 사내 오픈모델(`gemma4`, `qwen2.5`, `deepseek-r1`, `qwen2.5vl`)과 직결됩니다. 그 외에도 OpenAI, Gemini, Claude, FreeLLMAPI 및 중국 본토 5대 모델(Qwen, DeepSeek, GLM, Doubao, Kimi)까지 총 **11종 프리셋**을 기본 제공합니다.

### Q5. 인터랙티브 HTML5 키오스크 패키지(`.zip`)를 올렸을 때도 원격에서 실시간 화면 캡처 확인이 되나요?
**A:** 네! **멀티 OS 플레이어 `v2.2.0`** 엔진은 삼성 SSSP 하드웨어 프레임버퍼 캡처뿐만 아니라 **동적 HTML5 데이터 위젯 및 터치 키오스크 패키지 화면의 실시간 고해상도 원격 캡처**를 완벽 지원하여 현장에 가지 않고도 실제 렌더링 화면을 즉시 검증할 수 있습니다.

### Q6. 기간이 지난 프로모션 배너 오송출 방지나 인터넷 단절 시 재생은 어떻게 보장되나요?
**A:** 업로드 시 **멀티모달 비전(Vision) AI**가 배너 속 **행사 종료일(`detected_valid_until`)**을 자동 추출하여 만료 배너가 활성 스케줄에 남아 있으면 즉시 경보합니다. 또한 모든 에셋과 HTML5 패키지는 단말 로컬 스토리지에 프리캐싱되어 인터넷이 장기간 끊겨도 **영구 자율 오프라인 재생**을 보장합니다.

### Q7. 4계층 스케줄 우선순위, 전 자동 SyncPlay, 외부 AI 에이전트(MCP) 연동은 어떻게 작동하나요?
**A:** 스케줄은 `EMERGENCY > EVENT > REGULAR > DEFAULT` 순으로 선점 후 자동 복귀하며, **【같은 그룹 + 같은 스케줄 + 같은 LAN】** 단말들은 실시간 SSE 스트림으로 밀리초 단위 동시 전환(`SyncPlay`)됩니다. 또한 표준 **MCP 서버(`pingbao`)**와 60+ REST API가 기본 내장되어 Claude Desktop, Cursor, Antigravity, Dify 등 외부 에이전트와 즉시 연동됩니다.
