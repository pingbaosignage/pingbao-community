# 핑바오(Pingbao) 자주 묻는 질문 (FAQ)

### Q1. 매장 인터넷이 끊어지면 화면이 멈추거나 검은 화면이 되나요?
**A:** 전혀 그렇지 않습니다. 핑바오는 **"영구 자율 오프라인 재생(Autonomous Offline Loop)"**을 지원하도록 설계되었습니다. 스케줄 배포 시 모든 비디오 및 이미지 파일이 단말의 로컬 고속 스토리지에 사전 다운로드되며, 단말 내부의 독립된 상태 머신과 시계로 동작하므로 장기간 통신이 단절되어도 스케줄에 맞춰 무중단으로 완벽히 재생됩니다.

### Q2. 어떤 운영체제(OS)와 상용 사이니지 하드웨어를 지원하나요?
**A:** **삼성 스마트 사이니지(Samsung Smart Signage · Tizen 6.5+ / SSSP 6~10+)** 를 네이티브 `b2bapis` 하드웨어 드라이버로 심층 제어하는 것을 주력으로 지원하며, 이에 더해 **Windows 10/11 키오스크 PC(`.exe`)**, **Android 셋톱박스/태블릿(`.apk`)**, **Linux 미니 PC(`.deb` / `.sh`)**, **무설치 표준 웹 플레이어(`/player`)** 까지 **5대 멀티 OS 통합 관제**를 공식 지원합니다. 각 OS별 하드웨어 추상화 계층(HAL)이 지원 가능한 제어 항목(하드웨어 패널 전원 vs DPMS 소등, 하드웨어 백라이트 vs 앱 디밍 등)을 자동으로 매핑합니다.

### Q3. 현장 기기에 플레이어를 설치할 때 매번 서버 IP나 주소를 수동 입력해야 하나요?
**A:** 수동 입력이 필요 없습니다. 관리 콘솔 상단의 **[플레이어 설치 다운로드]** 모달에서 다운로드하는 모든 설치 패키지(삼성 Tizen USB `.zip`, Windows `.exe`, Android `.apk`, Linux `.deb`/`.sh`)에는 현재 서버 접속 주소가 자동으로 내장(Stamping)되어 있어, 설치 즉시 서버와 연결되고 화면에 표시되는 6자리 PIN 코드로 원클릭 페어링할 수 있습니다.

### Q4. 업로드 영상 크기에 제한이 있나요? 권장 코덱은 무엇인가요?
**A:** H.264 / AAC 코덱으로 인코딩된 MP4 및 WebM 형식을 권장합니다. 서버가 64바이트 매직 바이트 보안 검증과 디스크 직결 청크 스트리밍 업로드를 지원하므로 수 GB 단위의 4K 초고화질 대용량 영상도 메모리 부담 없이 원활하게 업로드하고 배포할 수 있습니다.

### Q5. 4계층 스케줄 우선순위와 타임파팅(Dayparting)은 어떻게 작동하나요?
**A:** `EMERGENCY`(비상 재난/VIP 의전) > `EVENT`(피크 프로모션) > `REGULAR`(일상 타임파팅) > `DEFAULT`(24시간 배경 폴백) 순서로 자동 선점됩니다. 이벤트 시간(예: 점심 11:30~14:00)이 끝나면 수동 개입 없이 일상 방송으로 부드럽게 무결점 복귀(Zero-flicker)합니다.

### Q6. SyncPlay 멀티스크린 동기화는 어떻게 동작하나요?
**A:** 복잡한 하드웨어 분배기나 수동 페어링이 필요 없습니다. 여러 대의 디스플레이가 **【같은 그룹】 + 【같은 스케줄】 + 【같은 네트워크(동일 LAN)】** 환경에 있으면, 실시간 네트워크 SSE SyncPlay 스트림과 클럭 오프셋 자동 보정을 통해 **100% 자동으로 밀리초 단위 프레임 싱크와 동시 화면 전환**이 활성화됩니다.

### Q7. 외부 시스템 연동을 위한 API 및 AI 에이전트(MCP)를 지원하나요?
**A:** 네, 전면 지원합니다. 60개 이상의 표준 OpenAPI 3.0 RESTful API와 **MCP (Model Context Protocol)** 서버를 기본 내장하고 있습니다. 조직·역할·작업 범위가 격리된 API 키 발급 및 호출량 모니터링을 제공하며, Claude Desktop, Cursor, Antigravity 등의 AI 에이전트가 자연어로 장치 진단, 가동시간 조회, 스케줄 편성 및 원격 제어를 직접 수행할 수 있습니다.

### Q8. 운영 로그와 PoP 데이터는 얼마나 보관되며, 오류 텔레메트리의 개인정보는 안전한가요?
**A:** 운영 관제 이력, 장치 가동시간 통계, 방송 송출 증빙(PoP), 사용자 감사 로그는 **기본 6개월(180일) 보존 주기 및 자동 정리(Auto-Purge Lifecycle)** 가 적용되어 장기 운영 시에도 디스크 고갈을 방지합니다. 또한 오류 텔레메트리는 기본 비활성화(Opt-in) 상태이며, 활성화 시에도 비밀번호, 토큰, 인증 헤더, IP, 연락처 등 모든 민감 데이터를 자동 마스킹(`***MASKED***`)한 뒤 SHA-256 지문 중복 제거를 거쳐 안전하게 리포팅합니다.
