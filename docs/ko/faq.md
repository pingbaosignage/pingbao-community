# 핑바오(Pingbao) 자주 묻는 질문 (FAQ)

### Q1. 매장 인터넷이 끊어지면 화면이 멈추거나 검은 화면이 되나요?
**A:** 전혀 그렇지 않습니다. 핑바오는 **"영구 자율 오프라인 재생(Autonomous Offline Loop)"**을 지원하도록 설계되었습니다. 스케줄 배포 시 모든 비디오 및 이미지 파일이 디스플레이 단말의 로컬 고속 스토리지에 사전 다운로드되며, 단말 내부의 독립된 상태 머신과 RTC 시계로 동작하므로 몇 달 동안 통신이 단절되어도 스케줄에 맞춰 완벽히 재생됩니다.

### Q2. 어떤 상용 사이니지 디스플레이를 지원하나요?
**A:** 삼성 스마트 사이니지 Standalone(Tizen 6.5+ / SSSP 10+ 탑재 모델인 QMB, QBB, QHB, QMC, QBC, QHC 등 전 라인업)을 네이티브 드라이버로 완벽 지원합니다. 또한 표준 Web Player 및 안드로이드 기반 상용 셋톱박스에서도 매끄럽게 동작합니다.

### Q3. 업로드 영상 크기에 제한이 있나요? 권장 코덱은 무엇인가요?
**A:** H.264 / AAC 코덱으로 인코딩된 MP4 및 WebM 형식을 권장합니다. 서버가 대용량 분할 스트리밍 업로드 및 청크 단위 캐싱을 지원하므로 수 GB 단위의 4K 초고화질 대용량 영상도 원활하게 업로드하고 분배할 수 있습니다.

### Q4. 4계층 스케줄 우선순위와 타임파팅(Dayparting)은 어떻게 작동하나요?
**A:** `EMERGENCY`(비상 재난/의전) > `EVENT`(피크 프로모션) > `REGULAR`(일상 타임파팅) > `DEFAULT`(24시간 배경 폴백) 순서로 자동 선점됩니다. 이벤트 시간(예: 점심 11:30~14:00)이 끝나면 사람이 개입하지 않아도 일상 방송으로 부드럽게 복귀(Zero-flicker)합니다.

### Q5. SyncPlay 멀티스크린 동기화는 무엇이며 별도 하드웨어가 필요한가요?
**A:** 카운터 상단 3~5연속 전자메뉴판을 위한 프레임 단위 동기화 기술입니다. 사내 표준 로컬 네트워크 NTP 시계를 기반으로 여러 화면이 동시에 전환되며, 고가의 비디오 월 매트릭스나 외부 스플리터 하드웨어 없이 소프트웨어만으로 울트라 와이드 영상을 분할 렌더링합니다.

### Q6. 오류 텔레메트리는 어떤 정보를 수집하며 개인정보는 안전한가요?
**A:** 기본적으로 비활성화(Opt-in)되어 있으며 슈퍼 관리자가 동의해야만 켜집니다. 런타임 오류 수집 시 데이터베이스 비밀번호, API 토큰, Bearer 인증 헤더, 사내 사설/공인 IP 및 전화번호 등 모든 민감 데이터를 정규식으로 자동 마스킹한 뒤 SHA-256 지문으로 중복 제거하여 GitHub 커뮤니티 이슈로 전송합니다.

### Q7. 버그나 개선 아이디어는 어디로 제안하나요?
**A:** [핑바오 커뮤니티 이슈 트래커](https://github.com/pingbaosignage/pingbao-community/issues)를 통해 **버그 리포트** 또는 **기능 제안**으로 등록해주시면 됩니다. 관리자가 검토 후 `accepted` 라벨을 부착하면 AI 에이전트가 자동 구현 및 테스트를 진행합니다. 콘솔 내의 **오류 보고 & 커뮤니티** 탭에서도 직접 등록할 수 있습니다.
