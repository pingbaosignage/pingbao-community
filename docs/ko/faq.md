# 핑바오(Pingbao) 자주 묻는 질문 (FAQ)

### Q1. 매장 인터넷이 끊어지면 화면이 멈추거나 검은 화면이 되나요?
**A:** 전혀 그렇지 않습니다. 핑바오는 **"영구 자율 오프라인 재생(Autonomous Offline Loop)"**을 지원하도록 설계되었습니다. 스케줄 배포 시 모든 비디오 및 이미지 파일이 삼성 사이니지 단말의 로컬 고속 스토리지에 사전 다운로드되며, 단말 내부의 독립된 상태 머신과 RTC 시계로 동작하므로 몇 달 동안 통신이 단절되어도 스케줄에 맞춰 완벽히 재생됩니다.

### Q2. 어떤 상용 사이니지 디스플레이를 지원하나요?
**A:** **삼성 스마트 사이니지(Samsung Smart Signage)** 만을 전문 지원합니다. Tizen 6.5+ / SSSP 10+ 기반의 QMB, QBB, QHB, QMC, QBC, QHC 등 삼성 상용 스마트 사이니지 전 라인업을 네이티브 b2bapis 드라이버로 완벽 제어합니다.

### Q3. 업로드 영상 크기에 제한이 있나요? 권장 코덱은 무엇인가요?
**A:** H.264 / AAC 코덱으로 인코딩된 MP4 및 WebM 형식을 권장합니다. 서버가 대용량 분할 스트리밍 업로드 및 청크 단위 캐싱을 지원하므로 수 GB 단위의 4K 초고화질 대용량 영상도 원활하게 업로드하고 분배할 수 있습니다.

### Q4. 4계층 스케줄 우선순위와 타임파팅(Dayparting)은 어떻게 작동하나요?
**A:** `EMERGENCY`(비상 재난/의전) > `EVENT`(피크 프로모션) > `REGULAR`(일상 타임파팅) > `DEFAULT`(24시간 배경 폴백) 순서로 자동 선점됩니다. 이벤트 시간(예: 점심 11:30~14:00)이 끝나면 사람이 개입하지 않아도 일상 방송으로 부드럽게 복귀(Zero-flicker)합니다.

### Q5. SyncPlay 멀티스크린 동기화는 어떻게 동작하나요?
**A:** 복잡한 하드웨어 분배기나 수동 페어링이 필요 없습니다. 여러 대의 삼성 사이니지가 **【같은 그룹】 + 【같은 스케줄】 + 【같은 네트워크(동일 LAN)】** 환경에 있으면, 시스템이 **100% 자동으로 감지하여 밀리초 단위 프레임 싱크와 동시 화면 전환**을 구현합니다.

### Q6. 외부 시스템 연동을 위한 API 및 AI 에이전트(MCP)를 지원하나요?
**A:** 네, 전면 지원합니다. 핑바오는 60개 이상의 엔드포인트를 갖춘 표준 OpenAPI 3.0 RESTful API와 표준 **MCP (Model Context Protocol)** 서버를 기본 내장하고 있습니다. API Key 발급 및 호출량 모니터링을 제공하며, Claude Desktop, Cursor, Antigravity 등의 최신 AI 에이전트가 자연어로 장치 조회, 스케줄 배포, 하드웨어 제어 도구를 직접 실행할 수 있습니다.

### Q7. 오류 텔레메트리는 어떤 정보를 수집하며 개인정보는 안전한가요?
**A:** 기본적으로 비활성화(Opt-in)되어 있으며 슈퍼 관리자가 동의해야만 켜집니다. 런타임 오류 수집 시 데이터베이스 비밀번호, API 토큰, Bearer 인증 헤더, 사내 사설/공인 IP 및 전화번호 등 모든 민감 데이터를 정규식으로 자동 마스킹한 뒤 SHA-256 지문으로 중복 제거하여 GitHub 커뮤니티 이슈로 전송합니다.

### Q8. 버그나 개선 아이디어는 어디로 제안하나요?
**A:** [핑바오 커뮤니티 이슈 트래커](https://github.com/pingbaosignage/pingbao-community/issues)를 통해 **버그 리포트** 또는 **기능 제안**으로 등록해주시면 됩니다. 관리자가 검토 후 `accepted` 라벨을 부착하면 AI 에이전트가 자동 구현 및 테스트를 진행합니다. 콘솔 내의 **오류 보고 & 커뮤니티** 탭에서도 직접 등록할 수 있습니다.
