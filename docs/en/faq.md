# Pingbao Frequently Asked Questions (FAQ)

### Q1. Will screens go blank or freeze if the network connection is lost?
**A:** No. Pingbao is architected around the **Autonomous Offline Loop** principle. Displays download and cache all necessary media assets and schedule rules locally before playing. Even if the network is disconnected for hours or days, displays continue autonomous playback indefinitely according to schedule rules.

### Q2. What hardware models are supported?
**A:** Pingbao natively supports Samsung Smart Signage Standalone displays running Tizen 6.5+ / SSSP 10+ (QMB, QBB, QHB, QMC, QBC, QHC series, etc.). Additionally, a Web Player client is supported for standard PC browsers and Android set-top boxes.

### Q3. What are the video size limits and supported codecs?
**A:** H.264 / AAC encoded MP4 and WebM formats are strongly recommended. The server supports streaming uploads and resumable chunked downloads for multi-gigabyte video files.

### Q4. How do I report a bug or request a new feature?
**A:** Please open an issue in the [Pingbao Community Issue Tracker](https://github.com/pingbaosignage/pingbao-community/issues) using the **Bug Report** or **Feature Request** templates. Once verified and given the `accepted` label by the project maintainer, the AI development agent will automatically begin work.
